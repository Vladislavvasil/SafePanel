# Панель мониторинга: погодные факторы для работы на улице, Санкт-Петербург

## Для кого и зачем
Для человека, который собирается работать или находиться на улице в Санкт-Петербурге
(курьер, строитель, дворник, турист). Панель показывает три связанных показателя
из текущих модельных данных: температуру воздуха, скорость ветра и осадки.
Значения не оцениваются как «опасные» или «безопасные» — собственных порогов нет,
для решений при непогоде даны ссылки на официальные предупреждения.

## Данные и источники
- API: Open-Meteo, Weather Forecast API — https://open-meteo.com/en/docs
  (данные по лицензии CC BY 4.0, условия: https://open-meteo.com/en/terms). Дата проверки: 25.10.2026.
- Адрес запроса:
  `https://api.open-meteo.com/v1/forecast?latitude=59.9386&longitude=30.3141&current=temperature_2m,wind_speed_10m,precipitation&wind_speed_unit=ms&timezone=Europe%2FMoscow`
  (координаты — Дворцовая площадь, Санкт-Петербург).
- Официальные материалы по теме (проверены 25.10.2026):
  - Гидрометцентр России — «Бюллетень опасных и неблагоприятных гидрометеорологических явлений»: https://meteoinfo.ru/hazardsbull
  - Главное управление МЧС России по г. Санкт-Петербургу — «Оперативная информация»: https://78.mchs.gov.ru/deyatelnost/press-centr/operativnaya-informaciya
- Единицы и время:
  - `current.temperature_2m` — температура воздуха на 2 м, единица из `current_units.temperature_2m` (°C);
  - `current.wind_speed_10m` — средняя скорость ветра на 10 м, `current_units.wind_speed_10m` (m/s, задано параметром `wind_speed_unit=ms`);
  - `current.precipitation` — сумма осадков за предыдущий интервал, `current_units.precipitation` (mm);
  - `current.interval` — длина интервала в секундах (900 с = 15 мин);
  - `current.time` — время, к которому относятся данные (московское время, т. к. `timezone=Europe/Moscow`).
  - Отдельно показывается время последней успешной загрузки — момент, когда браузер получил ответ.

## Как запустить
Открыть папку в VS Code, установить Live Server от Ritwick Dey,
запустить `index.html` через **Open with Live Server**. Проверить, что адрес
начинается с `http://127.0.0.1:5500/` (или `localhost`), а не с `file://`.
Backend и ключ не нужны: Open-Meteo работает без ключа и разрешает запросы из браузера (CORS).

## Ограничения
- Это модельный прогноз для ближайшего узла сетки, а не показания метеостанции;
  в конкретном районе города погода может отличаться. Порывы ветра не показаны.
- **Прогноз не является официальным оповещением о ЧС** и не заменяет предупреждения Гидрометцентра и МЧС.
- Данные могут отсутствовать: нет интернета, API недоступен, превышен лимит,
  ответ пришёл без нужного поля. Тогда показывается «Нет данных» или ошибка с кнопкой повтора,
  старые числа убираются, вымышленные значения не подставляются.
- Бесплатный тариф Open-Meteo: только некоммерческое использование,
  до 10 000 запросов в сутки, 5 000 в час и 600 в минуту.
- Доступность из России проверена 25.10.2026 открытием адреса запроса в браузере.
- Ключ не используется, поэтому секретов в коде нет.
